# Create the solution structure and follow the steps below to set up the Python project in Visual Studio:

1) Download the zip file and extract.
2) Open the extracted folder and open with Visual Studio (File > Open > Folder).
3) Install Python support in Visual Studio (Extensions > Manage Extensions).
Image
4) Study About Python Installation and Setup (https://learn.microsoft.com/en-us/visualstudio/python/python-web-application-project-templates?view=visualstudio).
5) Create Python Environment (Python Environments > Add Environment > Virtual Environment).
6) Install required packages (pip install -r requirements.txt).
7) Open the Main.py file and study the code.
8) Modify the code as needed and save the changes.
9) Select startup file: Main.py (right click on the file > Set as Startup File). 
10) Run the application (Debug > Start Debugging or press F5).
